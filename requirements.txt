# Runtime dependencies for the Switchboard / Watchtower backend.
# Install into the project venv before running `multicode-cli switchboard runner run`
# or starting the desktop app's embedded backend:
#     python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
#

# back to the legacy non-PTY wrapper path and "View live" affordances are
# hidden in the UI.
