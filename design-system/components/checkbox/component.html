Light — a form's checkboxes: marked now, read when the form is submitted.

Mixed — the parent is neither on nor off while some of its children are. Indeterminate is a DOM property, not an attribute, so it is set below in script; there is no HTML spelling for it.

No visible label — the control is named by aria-label instead. Correct only when the surrounding layout already makes the meaning obvious.

Dark — the box grounds on the app colour rather than the surface it sits on, so it reads as a well at any depth.
