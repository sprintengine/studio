# The stage names live in one place

Three modules each spell the stage names their own way, so a reader comparing
two of them cannot tell whether "collect" and "collection" are the same stage.

Define the names once and have every module read them from there. The rename is
mechanical; the value is that the vocabulary stops drifting.
