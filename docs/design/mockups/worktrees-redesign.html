What changed
  1. The answer comes first. How many worktrees can go, why that is safe, and that the cleanup takes them by itself. One button removes them now.
  2. One project at a time. Tabs instead of a page of stacked cards; the count says where the clutter is.
  3. The pool as tiles. Who holds each slot and when it was last used. When no slot is ready, the page says why ("held by open chats") and offers to settle the merged, quiet ones, which is what returns a slot.
  4. Every worktree, one table. Not just the app's: hand-made, agent CLI (.claude/worktrees) and stray ones too, with Origin saying which.
  5. Last used on every row, newest first, grouped Today / This week / Older. "Last used" is when its index or HEAD last moved, so a git gc or the page itself never counts.
  6. Filters that match the decisions: Can go, Not merged, Changes. Select many; the footer sums the space.
  7. Unmerged work waits a week. A clean worktree whose commits are on a branch goes after seven days unused; the branch stays, so nothing committed is lost. Uncommitted work, or commits only a detached HEAD holds, keep it.
  8. Pools shrink to nothing. A ready slot unused for a day is removed, so a project left alone drops its pool entirely.
  9. Opens at once. The page shows what it last read and refreshes underneath; sizes are re-measured only when over 15 minutes old.
