Decisions this mockup encodes

  • Fixed-size modal, wallpaper stays visible. Same shell contract as SettingsOverlay (max-w + max-h caps, centered, --shadow-drawer). The form gets a solid --bg-surface surface instead of floating on the wallpaper, and the layout stops fighting viewport height.
  • Type first, details second, one screen per type. The step wizard (name → mode → mode config) collapses into a rail selection plus a single config pane. No Continue chain; one primary action per type.
  • Footer is pinned. The scroll region is only the config body; the primary action never leaves the viewport. This is the fix for the scroll-to-continue defect, applied structurally.
  • Name is optional-first. Chat and most orchestrated types can derive a name from the folder or goal; only Workspace/Sprint surface the name field prominently.
  • Rail order mirrors the current picker: Chat, Workspace, then orchestrated types (Sprint, Design wizard, Multiloop, Automations, Switchboard), module-gated as today.
  • Sentence case, hairline structure, one accent per the aesthetic north star; recent-row mode reads as quiet text ("Sprint"), not a pill.
